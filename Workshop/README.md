# ورشة الصيانة — إدارة طلبات الصيانة

برنامج ويندوز مستقل لإدارة ورشة صيانة الهواتف والأجهزة. هو نسخة سطح المكتب من صفحة «ورشة الصيانة» (HTML)،
مكتوبة بنفس تقنية برنامج **رصيد**: C# ‏.NET 8 ‏WinForms وقاعدة بيانات SQLite، وبنفس مكتبة الواجهة (الأزرار والبطاقات والجداول والخطوط والأيقونات والألوان).

## التشغيل

```
cd Workshop
dotnet run
```

أو لبناء ملف تشغيل واحد:

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

يتطلب ويندوز 10 أو أحدث مع .NET 8 SDK للبناء.

- البيانات في `%LocalAppData%\RaseedWorkshop\workshop.db` (منفصلة تماماً عن بيانات رصيد).
- مكتبة الواجهة تُقرأ من `..\Raseed\UiKit` (مشتركة بين البرنامجين)، لذلك يجب أن يبقى المجلدان جنباً إلى جنب.

## الشاشات

| الشاشة | ما فيها |
|---|---|
| الرئيسية | أرقام اليوم / الأسبوع / الشهر، طاولة العمل (قيد الفحص، الإصلاح، انتظار قطعة، جاهز)، تنبيهات الأجهزة المتأخرة والجاهزة غير المستلمة والمخزون والديون والنسخ الاحتياطي |
| الطلبات | جدول أو لوحة (Kanban) حسب الحالة، بحث في كل الحقول، فلاتر سريعة، أعمدة قابلة للإخفاء (والتصدير CSV من الإعدادات) |
| طلب جديد / تعديل | الزبون والجهاز وIMEI (تحقق Luhn)، فحص الجهاز عند الاستلام، الملحقات، الصورة، القطع من المخزون، السعر والدفعات بطرق متعددة، الضمان وطلبات الضمان، التنبيه على إصلاح سابق لنفس الجهاز |
| الديون المستحقة | الزبائن المدينون من الأقدم، تسجيل دفعة، تذكير بالواتساب |
| الزبائن | كل زبون مع أجهزته ومجموع ما دفعه وما عليه |
| قطع الغيار والأسعار | حسب الموديل أو كجدول، الكميات وحد التنبيه، استيراد وتصدير CSV |
| حسابات الموردين | المشتريات والدفعات والرصيد وكشف الحساب |
| التقارير والمصاريف | الإيراد والربح والمقبوض لأي فترة، المخططات، أكثر الأعطال والأجهزة، المصاريف، تصدير Excel وطباعة |
| الأدوات | تقفيل اليوم، تعريفات الطابعات (مع تصحيح اسم الشركة)، المحذوفات، الإعدادات |

الطباعة (الفاتورة، ملصق الجهاز بباركود Code128، وصل الاستلام، التقارير) تُفتح في المتصفح مع نافذة الطباعة مباشرة، فتعمل مع أي طابعة ومع «الطباعة إلى PDF».

## الاختصارات

- `Ctrl+N` طلب جديد
- `Ctrl+K` بحث سريع عن طلب أو زبون أو أمر
- `F5` تحديث الشاشة
- قارئ الباركود: مسح ملصق الجهاز (المرجع) أو IMEI يفتح الطلب مباشرة

## نقل البيانات من نسخة المتصفح

من **الإعدادات ← النسخ الاحتياطي والبيانات ← استيراد من نسخة المتصفح**: اختر ملف JSON الذي صدّرته من صفحة HTML،
ثم «دمج» (يضيف الجديد فقط) أو «استبدال». الصور والقطع والمصاريف وحسابات الموردين وتعريفات الطابعات تُنقل كلها،
ويمكن التصدير بنفس الصيغة للرجوع إليها.

## النسخ الاحتياطي

- «نسخة احتياطية الآن» من الشريط العلوي (تُحفظ في `Backups` داخل مجلد البيانات، آخر 30 نسخة).
- النسخ التلقائي: اختر مجلداً (Google Drive / OneDrive / فلاشة) ليُحفظ فيه ملف لكل يوم بعد التعديلات.
- «مسح كل البيانات» يحفظ نسخة قبل المسح يمكن التراجع إليها.
